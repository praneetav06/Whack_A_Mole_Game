# Whack-a-Mole Game

A fun and interactive **Whack-a-Mole** game built using HTML, CSS, and JavaScript. Test your reflexes by hitting the moles as they pop out of their holes!

## Features

- **Interactive Gameplay**: Whack the moles with a click as they appear.
- **Score Tracking**: Keeps track of your score during the game.
- **Timer**: A countdown timer challenges players to score as much as possible within the time limit.
- **Responsive Design**: Play on both desktop and mobile devices.
- **Sound Effects**: Optional sound effects for an immersive experience.

## How to Play

1. Start the game by clicking the **Start** button.
2. Click on the moles as they pop up to earn points.
3. Keep an eye on the timer—the game ends when time runs out.
4. Your final score will be displayed at the end of the game.
